# ICS-TV ブランド素材

ICS-TVのロゴと、親ブランドである同人サークル「アイシーエス」のロゴです。

`ICS-TV` はプロジェクトブランド、「アイシーエス」は運営・制作主体の親ブランドとして使い分けます。

正式採用前の初版です。色、文字のアウトライン、商標・類似確認は別途行います。

| ファイル | 用途 |
|---|---|
| `icstv-symbol.svg` | ICS-TVシンボル単体 |
| `icstv-symbol-white.svg` | 暗色背景用シンボル |
| `icstv-horizontal.svg` | 白背景用の横長ロゴ |
| `icstv-horizontal-dark.svg` | 暗色背景用の横長ロゴ |
| `icstv-favicon.svg` | favicon・SNSアイコン |
| `aisies-circle-logo.svg` | 親ブランド「アイシーエス」 |
| `aisies-circle-logo-dark.svg` | 暗色背景用の親ブランド |
