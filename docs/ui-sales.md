## 設計方針（営業側）

- 記号体系は ui.md と共通。旧設計の **営業サブナビ**（ダッシュボード / 契約 / 線引き / 割付 / マスタ / 請求の 6 項目）は実装されていない — 現行ナビは `nav.ts` の「コンテンツ > CM割付（`/sales`）」と「経営・権利 > 請求（`/billing`）」の 2 項目のみで、その他は Django admin / 旧テンプレへ委譲（上記実装状況表）。
- 対象ロール（設計案）: **営業 / 管理者**（割付ビューは送出影響の確認用に**運用者も参照（△）**。経理は ui.md ロール表の請求行の側）。**現行実装は is_superuser/is_staff の 2 値のみ**で、この区分は 5 ロール RBAC（未実装）が前提。
- 営業 UI は「契約 → 割付 → 実績」のうち **契約と割付の可視化** に責務を限定し、実績集計・金額確定は billing 側（後半）に委ねる。営業 UI から金額に効く操作は契約登録・変更のみで、送出済み枠は不変（sales.md S11）。
- バッジ語彙は ui.md を継承し、営業ドメイン固有のものを以下に追加（各画面の凡例で再掲し自己説明性を保つ）。

- 各行ヘッダの種別 `◇/◆` = `ad_contract.kind`、状態ドット = `ad_contract.status`、契約番号 = `ad_contract.id`、題 = `ad_contract.title`、期間 = `period_start`–`period_end`。

- タイム契約は本数が無いため `sponsorship.monthly_fee` と `seconds_per_episode`、提供進行（契約期間内の経過日数）を表示。金額の月割り確定は billing（後半）。
- `◐pending` 考査の契約には行内に「割付対象外」警告を出す（S8）。`! 未割付` は線引き（`spot_order_band`）未登録で割付候補に乗らない状態。

## 3. 線引きエディタ（spot_order_band グリッド）

対象ロール: **営業 / 管理者**（運用者×）。1 つの `spot_order` に対し、曜日（月〜日）× 時間帯のグリッドを塗って希望時間帯（`spot_order_band`、複数可）を作る。背景陰影は選択 `channel` の `time_band_rank.rank`（▓A 濃 / ▒SB / ░B / · C）。channel 選択は必須（`spot_order.channel_id` と照合・単価根拠）。指定番組（`spot_order_program`）も同画面で指定する。

```
┌─ 営業 ▸ 線引きエディタ（spot_order #1 / 契約 #C-241 夏季キャンペーン）                    [×] │

│ channel [ ICS-1 ▼ ] ◆必須(spot_order.channel_id・単価根拠)   オーダー期間 06/01–06/30  200本  │
│ 塗りモード ●追加 ○消去   選択帯 [ クリア ]   ランク背景=time_band_rank: ▓A ▒SB ░B ·C        │
```
