# ARIB セーフティゾーン (16:9 HD) と CG／時計配置の指針

放送画面上の CG（Lバー・テロップ・**朝夕の時計**・提供など）をどこまで画面端に寄せてよいかの基準。
ARIB **TR-B4「アスペクト比16:9の画面におけるセーフティゾーン」** に準拠する。本書は実装（`clock/corner.html` 等）の
配置根拠を残すための要約。**一次規格(TR-B4)は ARIB の有償資料**のため、以下の数値は ARIB に帰属する二次情報からの整理であり、
厳密運用が要る場合は TR-B4 原本で確認すること。

## ゾーン定義 (16:9 HD)

| ゾーン | 使用可能率 | 各辺マージン | 1920×1080 換算 | 用途 |
|---|---|---|---|---|
| **アクションセーフ** (action safe) | **97.5%** | 1.25% | 横 24px / 縦 13.5px | 映像・装飾要素の外縁。**ここまで使用可** |
| **タイトルセーフ** (title safe) | **95%** | 2.5% | 横 48px / 縦 27px | 読ませる重要情報（文字スーパー）はこの内側 |

- マージン = (100% − 使用可能率) ÷ 2（中央基準で上下・左右に等配分）。
- 出典により表記揺れあり：ARIB電波産業会規定として広く挙がるのは上記 **97.5% / 95%**。一部の解説（2019年版）は
  「情報範囲 93% / 重要情報範囲 90%」とより保守的な値を提示する。旧来のガイドライン（4:3 由来）は「アクションセーフ90% / タイトルセーフ80%」。
- **「動画枠に対して98%まで使用できる」**という現場表現は、アクションセーフ **97.5%** を丸めたもの。実質同義。
- PC／WEB 配信のみ（オーバースキャン無し）の面は端まで使用可。本システムは YouTube/HLS 配信のため上記セーフを尊重する。

## ICS-TV への適用

- **朝夕の左上時計** (`deploy/playout-node/casparcg/template/clock/corner.html`, CG layer 1-36):
  - 箱（パネル）の外縁 = **アクションセーフ 97.5% の線**に配置 → `#clock { left:1.25%; top:1.25%; }`。
  - 時刻の数字は箱の内側パディング（左右 22px / 上下 10px）分さらに内側 → 概ね**タイトルセーフ(95%)付近**に収まる。
  - = 「箱はアクションセーフまで／読ませる文字はタイトルセーフ内」という放送局の時計の置き方に一致。
- 他の CG（Lバー 1-30 / 予告 1-35 / 速報 1-40 / 提供 1-50 など、[cg-layers.md](cg-layers.md)）も、文字主体のものはタイトルセーフ(95%)内、
  装飾・帯はアクションセーフ(97.5%)まで、を目安にする。
