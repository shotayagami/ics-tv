プライバシーポリシー

制定日: 2026年6月13日 / 改定日: 2026年6月18日 / 運営者: ICS-TV（Circle ICS）

ICS-TV（以下「本サービス」）は、24時間編成のリニア配信チャンネルを提供します。本ポリシーは、本サービスが取得・利用する情報の取り扱いを定めます。

1. 取得する情報

  • 会員登録情報: 会員登録時に、メールアドレス・パスワード（ハッシュ化して保管し、平文は保持しません）・ニックネーム・生年月（年と月。生年月日は取得しません）・性別（男／女／無回答）・郵便番号を取得します。あわせて、本人確認のために認証アプリ（TOTP）の秘密鍵を取得・暗号化保管する場合があります。
  • YouTube / Google アカウント情報: 本サービスの運営者が YouTube へライブ配信を行うために、運営者自身の Google アカウントで OAuth 連携を行います。スコープは https://www.googleapis.com/auth/youtube.force-ssl です。これは視聴者の情報ではなく、配信を行う運営者アカウントの権限です。
  • 決済情報: 有料サブスクに加入する場合、決済は決済代行事業者（Stripe）が処理します。クレジットカード番号等は Stripe が取り扱い、当社では保持しません。当社は加入状況（プラン・課金状態・次回更新日）と Stripe の顧客/サブスクリプション識別子のみを保持します。
  • アクセスログ等: 公開ページの閲覧に伴う一般的な技術情報（IP アドレス、ユーザーエージェント等）。

2. 会員情報の利用目的

  • 会員アカウントの認証・本人確認（メールによる確認コード、認証アプリのコード）およびアカウント管理。
  • 将来提供予定の機能（コメント等）でのニックネーム表示。
  • 生年月・性別・郵便番号は、サービス改善のための統計（年齢層・性別・地域別の集計）にのみ利用します。個人を特定する形での公開は行いません。

3. Google ユーザーデータの利用目的

OAuth で取得した権限は、次の目的にのみ使用します。

  • YouTube ライブ配信枠（liveBroadcast / liveStream）の作成・バインド・開始/終了の自動運行
  • 配信枠のタイトル・説明（番組情報）の設定・更新

4. Limited Use（限定的使用）

本サービスによる Google ユーザーデータの取得・利用・保存は、Google API Services User Data Policy（Limited Use 要件を含む）に準拠します。具体的には、取得したデータを上記の目的以外に使用せず、第三者へ販売・譲渡せず、広告目的に利用しません。人間による閲覧は行いません（ただし、ユーザーの明示的同意がある場合、セキュリティ目的、法令遵守、または運用上必要かつ匿名化・集計された範囲を除く）。

5. 第三者提供

法令に基づく場合を除き、取得した情報を第三者に提供しません。配信映像の再送出先（例: YouTube、Cloudflare）および決済処理（Stripe）は、各機能の実現に必要な範囲での利用に限られます。会員情報を広告目的で第三者に提供することはありません。

6. 保管とセキュリティ

OAuth のトークン（refresh token 等）および会員の認証アプリ秘密鍵は暗号化して保管します。会員のパスワードはハッシュ化して保管し、平文は保持しません。アクセスは必要最小限の運用者に限定します。

7. データの削除・連携解除

会員アカウントは、ログイン後マイページの「退会（アカウント削除）」からご自身で削除できます。削除すると登録情報（メールアドレス・ニックネーム・生年月・性別・郵便番号・認証設定）はすべて削除され、元に戻せません。お問い合わせ先からの削除依頼も承ります。
運営者は管理画面から YouTube 連携をいつでも解除でき、解除時に保管中のトークンを削除します。Google アカウント側からも アクセス権の管理 でいつでも権限を取り消せます。

8. 改定

本ポリシーは必要に応じて改定します。重要な変更は本ページで告知します。
